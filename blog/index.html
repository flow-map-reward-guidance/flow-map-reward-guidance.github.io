TL;DROverview

Guidance is usually framed as sampling a reward-tilted distribution $\tilde\rho(x)\propto e^{r(x)}\rho(x)$ — expensive in high dimensions and reliant on poorly understood approximations. We instead pose guidance as a deterministic optimal control problem. The flow map appears naturally in the optimal solution; popular single-trajectory methods (DPS, FlowDPS, FlowChef) are its coarsest approximation. The result is Flow Map Reward Guidance (FMRG): training-free, single-trajectory alignment using one frozen FLUX flow map to both integrate and guide the flow — matching or beating baselines with as few as 3 NFEs, up to 70× fewer than prior work.

FMRG across diverse rewards: aesthetic enhancement, compositionality, latent-space inverse problems, style transfer, and VLM rewards — all from one frozen flow map, training-free.

1Guidance as optimal control

A flow model integrates the probability-flow ODE $\dot x_t=b_t(x_t)$, $x_0\sim\rho_0$, to produce $x_1\sim\rho_1$. A flow map $X_{s,t}$ is the solution operator: it jumps from time $s$ to $t$ in one network evaluation, so $x_1=X_{0,1}(x_0)$.

Rather than approximate reward-tilt sampling, we minimize control effort against reward:

$\min_u \int_0^1 \tfrac{\lVert u_t\rVert^2}{2\lambda}\,dt - r(x_1^u)\quad\text{s.t.}\quad \dot x_t^u=b_t(x_t^u)+u_t.$

In the small-$\lambda$ limit (and as the optimal greedy correction for any $\lambda$), the optimal control is

$u_t(x)=\lambda\,\nabla X_{t,1}(x)^{\!\top}\nabla r\big(X_{t,1}(x)\big),$

which depends only on the present trajectory through the uncontrolled flow map — no particle ensemble, no resampling.

Overview. FMRG alternates exact flow-map steps with reward-gradient steps along a single trajectory (top), in contrast to reward-tilt sampling (e.g. SMC) which needs many particles, resampling, and many steps (bottom).

Algorithm

Operator splitting decomposes each step into an exact flow-map advance and a guidance update. The flow-map Jacobian projects the reward gradient onto the data-manifold tangent space (FMRG-J); dropping it gives the cheaper, backprop-free FMRG-E.

Flow Map Reward Guidance (FMRG)
Require: Flow map X, reward r, grid {tk}, strength λt(x), steps nopt
1: Sample x0 ~ ρ0
2: for k = 0 ... N-1 do
3:   x ← Xtk,tk+1(xtk) {flow map step}
4:   for j = 0 ... nopt-1 do
5:     u ← ∇Xtk+1,1(x)T∇r(Xtk+1,1(x)) {Jacobian}5:     u ← ∇r(Xtk+1,1(x)) {Euclidean}
6:     x ← x + (Δtk/nopt) λtk+1(x)·u
7:   end for
8: end for  ·  return x1

Jacobian vs. Euclidean gradients

Gradient options. The Jacobian projects $\nabla r$ onto the tangent space, keeping FMRG-J on-manifold; FMRG-E follows $\nabla r$ off-manifold — higher raw reward but reward hacking. Use FMRG-E for simple $\ell_2$ rewards, FMRG-J for complex neural rewards.

2A hierarchy of methods

Substituting the uncontrolled flow map for the controlled one gives FMRG; replacing the flow map with a single Euler step (the denoiser) recovers DPS. Many popular methods are special cases differing mainly in the guidance weight.

3Terminal distribution & early stopping

In a Gaussian model with quadratic reward, greedy guidance achieves the highest expected reward but contracts variance exponentially, while reward tilting and exact control contract only polynomially. Early stopping — guiding only on $[0,t_\mathrm{stop}]$ then running the uncontrolled flow — provably restores the polynomial scaling and mitigates mode collapse.

Terminal distribution. Greedy guidance is narrower than reward tilting or exact control; early stopping at $t_\mathrm{stop}=0.3$ recovers comparable variance. Empirically, $t_\mathrm{stop}=0.25$ improves GenEval at all NFEs.
